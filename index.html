총액 비교

동일조건 보정총액은 VAT 포함 환산액 + 추가/제외 항목 보정액입니다. 첫봄의 아일랜드 식탁·조적파티션 추가비는 미확정입니다. 디자인허브는 협의가 9,000만원(VAT 포함)을 기준으로 시뮬레이션합니다.

원견적 전체 항목

받은 견적서의 금액 라인을 최대한 그대로 옮긴 탭입니다. 업체별 항목명이 달라도 여기서는 원문 구조를 유지합니다.

정규화 비교

모든 업체를 다시 수동 매핑했습니다. 변경이 없는 경우에는 중복되는 기본 금액을 숨기고, 옵션/시뮬레이션으로 금액이 달라진 경우에만 기본 금액을 표시합니다. 문구 자동분류를 제거하고 견적서의 원래 섹션과 실제 총액 포함 여부를 기준으로 금액행을 배치했습니다. 각 공종의 공종 소계 = 원견적 금액항목 합계가 되도록 검산하며, 일치하면 ✓를 표시합니다. 선택사항·견적안내·금액란 공란 항목은 합계에서 제외합니다. 공종 소계 행을 클릭하면 해당 공종의 세부 항목을 접기/펼치기 할 수 있고, 표 위의 버튼으로 전체 접기/전체 펼치기도 가능합니다. 공종 기타는 항상 맨 아래에 표시됩니다. 예론가는 정규화 공종합계가 78,936,900원(VAT 별도)이 되도록 누락 항목을 보정했으며, VAT 10% 적용 시 상단 총액 86,830,590원과 일치합니다. 접힘 상태도 같은 브라우저에서 저장됩니다. 맨 왼쪽 내 기준 견적은 직접 입력·저장하는 영역입니다. 업체별 금액 아래에 현재 적용 사양/옵션명을 표시하고, 비교 메모는 해당 업체에 관련된 내용만 그 업체 칸에 표시합니다. 다른 업체 칸에는 반복하지 않습니다.
