총액 비교

비교 총액은 VAT 포함 환산액에 사용자 추가공사와 옵션 증감을 반영한 금액입니다. 비브로디자인은 VAT 10%를 반영합니다. 156디자인은 견적서 최종 VAT포함 금액 87,000,000원을 사용합니다. 도사디자인은 견적서상 64,070,380원이 부가세 미포함으로 표시되어 있으며 VAT 청구 여부 확인 전까지 10%를 가정해 70,477,418원으로 비교합니다. 소유홈은 턴키가 아니라 반셀대행으로, 총 예상비용 57,068,000원은 시공비 51,880,000원 + 감리비 10%이며 세금계산서/현금영수증 발행 여부와 A/S는 공정별 업체 기준입니다. 첫봄의 아일랜드 식탁·조적파티션 추가비는 미확정입니다. 디자인허브는 협의가 9,000만원(VAT 포함)을 기준으로 시뮬레이션합니다.

원견적 전체 항목

받은 견적서의 금액 라인을 최대한 그대로 옮긴 탭입니다. 업체별 항목명이 달라도 여기서는 원문 구조를 유지합니다.
정규화 원칙 · 원견적에 없는 임의 분할은 하지 않고, 업체가 일괄로 제시한 항목은 '일괄'로 표시합니다. 비교 편의를 위해 디자인허브의 주방→설비, 세탁실→창호, 마감→기타처럼 1개 업체만 존재하던 상위 공종은 공통 공종으로 묶었습니다. 소유홈의 타일·도기 1,065만원은 욕실과 기타 타일이 함께 묶인 금액이므로 욕실 공종에 표시하되 '기타 타일 포함'으로 명시했습니다.

정규화 비교

모든 업체를 다시 수동 매핑했습니다. 투핸즈의 세탁실 터닝도어 100만원은 원견적에 없는 사용자 임의 추가 항목이며, 투핸즈 VAT는 50%만 반영(실질 5%)합니다. 변경이 없는 경우에는 중복되는 기본 금액을 숨기고, 옵션/시뮬레이션으로 금액이 달라진 경우에만 기본 금액을 표시합니다. 문구 자동분류를 제거하고 견적서의 원래 섹션과 실제 총액 포함 여부를 기준으로 금액행을 배치했습니다. 각 공종의 공종 소계 = 원견적 금액항목 합계가 되도록 검산하며, 일치하면 ✓를 표시합니다. 선택사항·견적안내·금액란 공란 항목은 합계에서 제외합니다. 공종 소계 행을 클릭하면 해당 공종의 세부 항목을 접기/펼치기 할 수 있고, 표 위의 버튼으로 전체 접기/전체 펼치기도 가능합니다. 공종 기타는 항상 맨 아래에 표시됩니다. 예론가는 정규화 공종합계가 78,936,900원(VAT 별도)이 되도록 누락 항목을 보정했으며, VAT 10% 적용 시 상단 총액 86,830,590원과 일치합니다. 접힘 상태도 같은 브라우저에서 저장됩니다. 업체별 금액 아래에 현재 적용 사양/옵션명을 표시하고, 비교 메모는 해당 업체에 관련된 내용만 그 업체 칸에 표시합니다. 다른 업체 칸에는 반복하지 않습니다.
