총액 비교

동일조건 보정총액은 VAT 포함 환산액 + 추가/제외 항목 보정액입니다. 첫봄의 아일랜드 식탁·조적파티션 추가비는 미확정입니다. 디자인허브는 협의가 9,000만원(VAT 포함)을 기준으로 시뮬레이션합니다.

원견적 전체 항목

받은 견적서의 금액 라인을 최대한 그대로 옮긴 탭입니다. 업체별 항목명이 달라도 여기서는 원문 구조를 유지합니다.

정규화 비교

맨 왼쪽 내 기준 견적은 내가 원하는 항목별 금액과 메모를 직접 저장하는 영역입니다. 같은 GitHub Pages 주소와 같은 브라우저라면 HTML을 새 버전으로 교체해도 값이 유지됩니다. 업체 열에서는 기존처럼 기본견적/제외/옵션변경을 시뮬레이션할 수 있습니다.
